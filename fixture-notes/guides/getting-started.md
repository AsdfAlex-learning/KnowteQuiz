# Getting Started with KnowteQuiz

Welcome to KnowteQuiz! This guide walks you through the basics.

## Setup

1. Install from the release page or build from source.
2. Point the app to your notes folder.
3. Configure your LLM endpoint (default: Ollama at `localhost:11434`).

## Creating Quizzes

Select a note in the explorer, then use the quiz panel to generate questions.

### Question Types

- **Single Choice**: Pick one correct answer from options.
- **Multiple Choice**: Select all correct answers.
- **Short Answer**: Type your answer in free text.

### Quiz Modes

- **Basic Mode**: Answer questions and see your score immediately.
- **Advanced Mode**: Submit your reasoning and get a detailed blind-spot diagnosis.

## Reviewing Mistakes

Mistakes are saved automatically. Open the **Error Book** tab to review them, filter by mode, or export as JSON/Markdown.
