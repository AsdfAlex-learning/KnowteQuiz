## 4. Mermaid 支持计划（已定稿，未实施）

**决策**：渲染器 = **mermaid.js**（MIT）；GPL 的 flowmaid 因许可证排除；不从零写 Rust 编译器（现成 MIT crate `mermaid-rs-renderer` 0.3.1 可作未来后端，但 0.3.x 成熟度/兼容性存疑）。覆盖面 = **全部 Markdown 表面**（阅读器 + 出题/诊断 + 探索白板/旁支）。

**架构**：

```mermaid 围栏 → markdown-it fence 规则（installMermaidFence，源码转义后进占位 div）
  → 全局指令 v-mermaid → 动态 import('mermaid') → mermaid.render(递增 id, src)
  → 成功=内联 SVG；失败=源码 <pre> + 错误提示
```

**要点**：

- `securityLevel: 'strict'`；theme 按 preset kind 映射（dark→'dark' / light→'default'），主题切换清 `data-processed` 重渲
- CSP 预计无需改（script-src 'self' / style-src 'unsafe-inline' / img-src data: 均已满足），实施时实测确认
- 已知坑：阅读器搜索 `doSearch`/`clearFind` 重置 innerHTML，之后必须显式重渲 mermaid，否则图消失
- mermaid id 用全局递增计数器防冲突

**分支**：`feat/mermaid-core`（依赖+围栏+渲染工具+指令+阅读器+测试）→ `feat/mermaid-surfaces`（出题/诊断/探索+主题重渲）→ `docs/mermaid`（README/TECH_SPEC/AGENTS）

**测试**：fence 转义与 XSS、渲染工具 mock 成功/失败/幂等、指令挂载；jsdom 无 getBBox，单测必须 mock mermaid

**计划原文只存在于会话对话中**（本文件为摘要）；如需完整版，实施前扩写 `docs/mermaid-support-plan.md`
